# 06_DHT_Thermometer — термометр на STM32F407 Discovery + DHT22 + DHT11

Проект собран на основе вашего `03_UART_hello` (те же настройки CubeIDE, HAL и линкер-скрипт),
лежит в той же рабочей области `STM32F407DISC1`.

## 1. Что подключить

Питание датчиков — от пина **3V** платы (не 5V), так линия данных остаётся 3.3 В, как у МК.

| Датчик | VCC | DATA | GND |
|--------|-----|------|-----|
| DHT22  | 3V  | **PB0** | GND |
| DHT11  | 3V  | **PB1** | GND |

* Названия пинов (PB0, PB1, 3V, GND) подписаны на плате рядом с гребёнками.
* Если у датчика **4 ножки** (голый датчик) — между VCC и DATA поставьте резистор 4.7–10 кОм.
  Если это плата-модуль с **3 ножками** — резистор уже на плате, ничего добавлять не надо.
* Ножка NC (у 4-ножечных) никуда не подключается.

Вывод в терминал (необязательно): **PA2 → RX** USB-UART адаптера, **GND → GND**, 115200 бод, 8N1.

## 2. Запуск

1. CubeIDE → **File → Open Projects from File System…** → папка `06_DHT_Thermometer` → Finish.
2. Молоточек (Build). Должно собраться без ошибок.
3. Жук (Debug) или Run — прошивка загрузится через ST-LINK. Нажмите Resume (F8), если остановилось на `main`.

## 3. Что вы увидите

**Светодиоды на плате** (по показаниям DHT22, если он молчит — по DHT11):

| Светодиод | Температура |
|-----------|-------------|
| синий     | ниже 18 °C |
| зелёный   | 18–26 °C |
| оранжевый | 26–30 °C |
| красный   | выше 30 °C |
| все 4 мигают 3 раза | оба датчика не ответили — проверьте проводку |

**Терминал** (раз в 2 секунды):

```
DHT22: T = 24.3 C, H = 45.1 %   |   DHT11: T = 24.0 C, H = 46.0 %
```

**Без адаптера:** в режиме Debug откройте **Live Expressions**, добавьте `dht22` и `dht11`.
`temp_x10 = 243` означает 24.3 °C, `hum_x10 = 451` — 45.1 %. Поле `dht22_status` / `dht11_status`: `0` = всё хорошо.

## 4. Если не работает

| Симптом | Причина |
|---------|---------|
| `no response` | датчик не запитан, DATA не на тот пин, нет подтяжки 4.7–10 кОм |
| `checksum mismatch` | редкие ошибки — нормально для DHT11; частые — длинные провода/помехи |
| все светодиоды мигают | оба датчика молчат — проверьте питание и GND |
| Нет текста в терминале | проверьте PA2→RX (не TX→TX), 115200 бод, общий GND |

## 5. Как устроен код

* `Core/Src/main.c` — главный цикл: опрос → вывод → светодиоды (весь ваш код внутри `USER CODE`-блоков).
* `Core/Src/dht.c`, `Core/Inc/dht.h` — драйвер датчиков (протокол описан в комментарии в `dht.h`).
* `Core/Src/uart_log.c` — вывод текста через USART2 без printf.

## 6. Заметка про 03_UART_hello

В том проекте тактирование USART2 включалось записью в `RCC->AHB1ENR` (бит 17), а USART2 сидит на шине
APB1 — нужно `RCC->APB1ENR |= RCC_APB1ENR_USART2EN`. Из-за этого UART там не оживает, а цикл
ожидания `TXE` зависает. В этом проекте это исправлено (см. `uart_log.c`).
